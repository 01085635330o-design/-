# 재활운동센터 회원관리 프로그램

구글시트를 데이터베이스로 사용하는 모바일 친화적 회원관리 웹앱입니다.
설치 프로그램이 아니라 웹페이지이므로, 스마트폰/PC 브라우저에서 바로 열어서 씁니다.

## 주요 기능

- **회원 관리**: 이름/연락처/생년월일, 이용권 종류(횟수권/기간권), 총·잔여 횟수, 시작일/만료일, 담당 트레이너, 상태(활성/휴면/만료)
- **출석 체크**: 회원 검색 후 원터치 출석 처리, 출석 시 잔여횟수 자동 차감
- **재활 기록**: 방문일자별 통증 부위/증상, 운동 내용, 통증 강도, 담당 트레이너 메모
- **결제/매출 관리**: 결제 등록, 월별 매출 합계, 회원별 결제 내역
- **대시보드**: 활성 회원 수, 이번달 신규 등록, 이번달 매출, 오늘 출석, 만료 임박(7일 이내) 회원, 잔여횟수 부족 회원

모든 데이터는 원장님의 구글 계정 안 구글시트에 저장됩니다. 여러 직원이 각자의 폰/PC에서
같은 링크로 접속하면 동일한 데이터를 실시간으로 확인·입력할 수 있습니다.

## 설정 방법 (최초 1회, 약 5분)

1. [Google Sheets](https://sheets.google.com)에서 새 스프레드시트를 만듭니다. (예: "재활운동센터 회원관리")
2. 메뉴에서 **확장 프로그램 → Apps Script** 를 클릭합니다.
3. 열린 편집기의 기존 코드를 지우고, 이 폴더의 [`Code.gs`](./Code.gs) 내용 전체를 복사해서 붙여넣은 뒤 저장합니다.
4. 우측 상단 **배포 → 새 배포**를 클릭합니다.
   - 유형 선택(⚙️): **웹 앱**
   - 실행 계정: **나**
   - 액세스 권한이 있는 사용자: **전체(익명 포함)** — 이래야 앱에서 접속할 수 있습니다.
   - **배포**를 누르고 권한을 승인합니다.
5. 배포 완료 후 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec` 형식)을 복사합니다.
6. [`index.html`](./index.html)을 웹에 올리거나(예: GitHub Pages) 파일을 그대로 더블클릭해서 브라우저로 엽니다.
7. 우측 상단 ⚙ **설정** 버튼을 눌러 방금 복사한 웹 앱 URL을 붙여넣고 **저장** → **연결 테스트**로 확인 → **시트 초기화**를 눌러 회원/출석/재활기록/결제 시트를 자동 생성합니다.

이후로는 스프레드시트를 열어 직접 데이터를 봐도 되고, 앱 화면에서 관리해도 됩니다.

## 📱 수업 리마인드 자동 문자 발송 (선택 기능)

기존에 쓰시던 요일별/시간대별 수업 스케줄표를 구글시트에 그대로 붙여넣어두면,
**수업 시작 12시간 전에 자동으로 문자(SMS)**를 보내드립니다.

> 카카오톡 알림톡은 사업자등록증 + 카카오 비즈니스채널 개설 + 메시지 템플릿 심사가 필요해서
> 지금 단계에서는 문자(SMS)로 먼저 구축했습니다. 나중에 사업자등록을 하시면
> `Reminder.gs`의 `sendSms()` 함수만 카카오 알림톡 API 호출로 바꿔서 그대로 전환할 수 있습니다.

### 설정 방법

1. **스케줄표 시트 만들기**: 스프레드시트 하단에 `스케줄표`라는 이름으로 새 시트를 만들고,
   기존에 쓰시던 표(1행: `TIME/DATE`, `일`, `월`, `화`, `수`, `목`, `금`, `토` / 이후 "9:00" 같은 시간마다
   이름행 + 메모행 2줄 1세트)를 그대로 복사해서 붙여넣습니다.
   - 요일 열 순서가 이미지와 다르면 `Reminder.gs` 상단의 `REMINDER_CONFIG.FIRST_DAY_COL` 숫자를 조정하세요.
   - 스케줄표의 이름 칸에 "SMC 김단비 회원님"처럼 다른 글자가 섞여 있어도, `회원` 시트에 등록된 이름이
     그 안에 포함되어 있으면 자동으로 매칭됩니다 (동명이인이 없다는 전제).
2. **Apps Script에 코드 추가**: Apps Script 편집기에서 파일 목록 옆 **+ → 스크립트**를 눌러 새 파일을
   만들고 이름을 `Reminder`로 지정한 뒤, [`Reminder.gs`](./Reminder.gs) 내용을 통째로 붙여넣고 저장합니다.
   (`Code.gs`는 그대로 둡니다 — 두 파일이 같은 프로젝트 안에서 서로 연결되어 동작합니다.)
3. **문자 발송업체(알리고) 가입**: [smartsms.aligo.in](https://smartsms.aligo.in)에서 무료 가입 후
   발신번호를 인증하고 **API 키 / 사용자 ID**를 발급받습니다. (사업자등록 없이 개인 인증만으로 가능)
4. **API 키 등록**: Apps Script 편집기 좌측 톱니바퀴(**프로젝트 설정**) → **스크립트 속성**에서 아래 3개를 추가합니다.
   - `ALIGO_API_KEY` : 알리고에서 발급받은 API 키
   - `ALIGO_USER_ID` : 알리고 사용자 ID
   - `ALIGO_SENDER` : 알리고에 등록/인증한 발신번호 (예: 0212345678)
5. **스프레드시트를 새로고침**하면 상단 메뉴에 **🔔 수업 리마인더**가 생깁니다.
   - **지금 한 번 확인/발송 테스트**: 실제로 문자가 나가는지, 몇 명이 매칭됐는지 바로 확인합니다.
   - **자동발송 트리거 설치(매시 정각)**: 이후로는 매시 정각마다 자동으로 "12시간 뒤" 수업을 확인해서 문자를 보냅니다.

발송 기록은 자동 생성되는 `발송이력` 시트에서 확인할 수 있고, 같은 수업에 두 번 발송되지 않도록
자동으로 중복 체크됩니다.

## 참고

- Apps Script 웹 앱은 무료이며 구글 계정만 있으면 됩니다. 별도 서버 비용이 들지 않습니다.
- 회원 삭제는 되돌릴 수 없으니 주의해서 사용해주세요. 실수 방지를 위해 상태를 "휴면"으로 바꾸는 것도 방법입니다.
- 여러 직원이 동시에 접속해서 사용할 수 있습니다. 각자 브라우저에서 설정 화면에 같은 웹 앱 URL을 입력하면 됩니다.
- 회원 목록을 엑셀로 백업/분석하고 싶다면, 연결된 구글시트를 파일 → 다운로드 → Microsoft Excel(.xlsx)로 내보내면 됩니다.
